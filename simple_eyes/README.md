The programs here generate compound-ray eye files.

These are space-separated text tables containing the parameters for
each ommatidium in a compound eye (one row per ommatidium).

for an example eye file, see `c_ray_mathplot/data/eyes/poly.eye`,
which was generated by the program `c_ray_mathplot/simple_eyes/make_poly_eye.cpp`.

In the eye file, the columns in a row contain these elements:

`x y z nx ny nz aa fo`

Where:

* x:   x coordinate of ommatidium in scene units
* y:   y coordinate of ommatidium in scene units
* z:   z coordinate of ommatidium in scene units
* nx:  x coordinate of ommatidium's normal vector (its direction)
* ny:  y coordinate of ommatidium's normal vector
* nz:  z coordinate of ommatidium's normal vector
* aa:  The acceptance angle in radians
* fo:  Focal point offset in scene units

The values of x, y and z for each ommatidium are interpreted as being
the same as the units that specify the scene model. So if '1' means 1
metre in your scene model, and you want an eye with a radius of 1 cm,
then the values in x, y and z are likely to be of the order of 0.01.

The eye file is used within a compound-ray gltf file. in the gltf, a
camera is created which has a link to the eye file.

For example, in the example `c_ray_mathplot/data/axis_coloured_blocks.gltf` example you will find (if you open it with a text editor) this
camera section which specifies the `data/eyes/hexy.eye` file:

```
  "cameras":[
    {
      "extras":{
        "compound-eye":"true",
        "compound-projection":"spherical_orientationwise",
        "compound-structure":"data/eyes/hexy.eye"
      },
      "name":"Camera",
      "perspective":{
        "aspectRatio":1.7777777777777777,
        "yfov":0.39959652046304894,
        "zfar":100,
        "znear":0.10000000149011612
      },
      "type":"perspective"
    }
  ],
```
